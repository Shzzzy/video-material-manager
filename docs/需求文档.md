# 创意素材工作台（CreativeAsset Workspace）需求文档

> 版本：v1.0　|　日期：2026-08-27　|　状态：已整理，待确认

## 一、项目定位

面向视频创作团队的一站式素材管理网站：

- **自动分类**拍摄素材（AI 视觉识别 + 用户自定义标签体系）
- **记录素材使用次数**（素材被哪些成片引用过、用了多少次）
- 分为**成片库**与**素材库**两大板块
- 预留**视频发布 API** 与 **AI 视频制作 API** 的外接接口（接口文档后续提供，先做适配器框架）
- 界面参考设计稿：高级、流畅、自然、美观

## 三、功能需求

### 3.1 素材库（核心）
| 功能 | 说明 |
|---|---|
| 素材录入 | 上传视频文件，或扫描服务器指定文件夹；自动生成编号、缩略图、指纹、基础信息（时长/分辨率/大小/拍摄时间） |
| 自动分类 | 调用可配置的 AI 视觉 API 识别场景/景别/内容并打标签；**未配置 API 时降级为手动打标**（不阻塞使用） |
| 自定义标签体系 | 用户自定义分类维度（如：拍摄人员、场景、景别、剪辑人员），每个维度下可增删标签值；维度与标签均入库 |
| 素材检索 | 按编号 / 文件名 / 标签组合搜索与筛选 |
| 黄金3秒标记 | 素材可标记「黄金3秒」（高价值开场片段），支持只看黄金3秒筛选 |
| 使用次数 | 每次素材被成片引用，使用次数 +1；记录使用历史（时间、成片、用途） |

### 3.2 成片库
| 功能 | 说明 |
|---|---|
| 成片管理 | 登记成片：标题、封面、时长、描述、发布状态 |
| 素材关联 | 从素材库勾选素材加入成片 → 自动累计素材使用次数 |
| 发布集成（预留） | 外接发布视频 API 的适配器接口（文档后补） |
| AI 视频制作（预留） | 外接 AI 视频生成 API 的适配器接口（文档后补） |

### 3.3 使用记录
- 按素材查看：被哪些成片使用、使用时间、使用次数
- 按成片查看：引用了哪些素材

## 四、技术方案

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS | 现代、流畅的 SPA |
| 后端 | Node.js + Express | 轻量 REST API |
| 数据库 | SQLite（better-sqlite3） | 单文件、零配置；预留迁移 PostgreSQL |
| 视频处理 | ffmpeg-static / ffprobe-static | 提取缩略图、读取时长分辨率（无需系统安装 ffmpeg） |
| 存储 | 本地磁盘（uploads/），元数据入库；缩略图/指纹入库或磁盘 | 符合「原片不发送云端」原则；对象存储留作后续扩展 |
| 指纹 | 文件 SHA-256 | 去重、识别素材使用来源 |

### 目录结构（单仓库前后端分离）
```
creative-asset-workspace/
├── client/            # React 前端
├── server/            # Express 后端
│   ├── src/
│   │   ├── routes/    # 路由
│   │   ├── services/  # 业务（素材/成片/标签/统计）
│   │   ├── lib/       # 视频处理、指纹、数据库
│   │   └── adapters/  # 预留：publish（发布）/ ai-video（AI视频）/ ai-vision（AI分类）
│   └── data/          # SQLite 数据库文件 + 上传目录（gitignore）
├── docs/              # 文档
└── README.md
```

## 五、API 适配器设计（预留，待接口文档）

三个可插拔适配器，统一以配置驱动（`server/config/adapters.json`）：

1. **ai-vision**（AI 素材分类）：请求视觉模型 API，返回标签建议；未配置 → 手动打标
2. **publish**（视频发布）：发布成片到外部平台
3. **ai-video**（AI 视频制作）：调用 AI 生成视频素材/成片

每个适配器定义统一接口（初始化 / 调用 / 错误处理），待用户提供文档后填充具体实现。
